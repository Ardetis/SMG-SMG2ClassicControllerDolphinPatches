# SMG and SMG2 Classic Controller Dolphin Patches
Classic Controller patches and mapping images, originally created as Riivolution files by SuperHackio, converted to patches for easier use with Dolphin.

[Original SMG classic controller riivolution patch by SuperHackio](https://youtu.be/0evN_8UFGjA?si=LNrhfbt0XWt0uJ0h)

[Original SMG2 classic controller riivolution patch by SuperHackio](https://youtu.be/KNAMVv-4W4g?si=bcPmamEiJh4DHS)

## Repository contents

- `SMG` and `SMG2` contain the patches converted for Dolphin's Patch system.
- `Riivolution Patches/SMG` and `Riivolution Patches/SMG2` contain the corresponding regional Riivolution XML files.

### SMG pointer setup

For SMG, enable exactly one controller style: **Nvidia** or **All-Stars**.

- To control the pointer with the Classic Controller right stick, also enable **Right-Stick Pointer** and exactly one **Pointer Speed** patch.
- To use Dolphin IR, leave **Right-Stick Pointer** and every **Pointer Speed** patch disabled.
- The L/ZL and R/ZR swap patches are optional and can be enabled alongside the selected controller style.

The regional `SMG-ClassicController-*.txt` file is the all-in-one version. It contains the same controller-style, pointer, speed, and swap choices as separate entries under one `[OnFrame]` section. Dolphin presents these entries as individual checkboxes.

### SMG2 pointer setup

For SMG2, enable exactly one controller style: **Nvidia** or **All-Stars**.

- To control the pointer with the Classic Controller right stick, also enable **Right-Stick Pointer** and exactly one **Pointer Speed** patch.
- To use Dolphin IR, leave **Right-Stick Pointer** and every **Pointer Speed** patch disabled.
- The L/ZL and R/ZR swap patches are optional and can be enabled alongside the selected controller style.

The regional `SMG2-ClassicController-*.txt` file is the all-in-one version. It contains the same controller-style, pointer, speed, and swap choices as separate entries under one `[OnFrame]` section. Dolphin presents these entries as individual checkboxes.

<summary><b>Android</b></summary>

7. Enable the code

5. Enter a name for your code (e.g., `$ Classic Controller Nvidia`)
6. Paste your copied code below the name of the code

9. Enable the code
